# Plataforma de monitoria e quizzes

## Objetivo

Uma plataforma de apoio aos estudos com progressão gamificada, revisão de conteúdo e exercícios de programação.

## Funcionalidades propostas

- Trilhas de conteúdo e resumos.
- Revisão com dez questões e feedback.
- XP, títulos, ranking e desafios difíceis.
- Personagem de professor para dicas.
- Área de prática de código.
- Tema claro/escuro.
- Possível integração com IA para sugerir perguntas e explicações.

## Situação

As funcionalidades foram discutidas como especificação de produto. Não devem ser tratadas como implementadas sem código e testes verificáveis.

## Próximos passos

1. Construir interface navegável.
2. Implementar conteúdo e quiz com perguntas de exemplo.
3. Persistir progresso com modelo de dados claro.
4. Adicionar autenticação segura apenas se necessária.
5. Adicionar acessibilidade, testes e limites para conteúdo gerado por IA.
