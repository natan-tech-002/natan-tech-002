## Princípios de organização

- Cada projeto deve ter seu próprio README, dependências e instruções de execução.
- Nunca versionar senhas, tokens privados, chaves Supabase `service_role` ou dados pessoais reais.
- Marcar claramente o que está implementado, planejado ou precisa ser validado.
- Adicionar testes e evidências reais de execução antes de declarar uma versão pronta.
